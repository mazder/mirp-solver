📁 Top-Level Directory Structure
mirp_sim/
├── CMakeLists.txt                  # Full build system for CPU/GPU/MPI
├── main.cpp                        # Initializes MPI, GPU device, runs simulation

├── config/                         # Setup from CGNS files
│   ├── cgns_interface.cpp/hpp      # Read/write mesh, BCs, physics params
│   ├── physics_loader.cpp/hpp      # Extract material props (bone, tumor, etc.)
│   └── simulation_config.hpp       # Structs for all loaded config values

├── core/                           # High-level simulation logic
│   ├── mirp_sim.cpp/hpp            # The main simulation controller class
│   ├── memory_manager.cpp/hpp      # GPU/CPU memory handler w/ label-based map
│   └── types.hpp                   # Enums, field tags, solver mode, etc.

├── setup/                          # Mesh, geometry, and DOF setup
│   ├── mesh_loader.cpp/hpp         # CGNS mesh loader (volume + boundary)
│   ├── boundary_conditions.cpp/hpp # Load BCs and tag boundaries
│   ├── field_initializer.cpp/hpp   # Allocate and initialize fields
│   └── domain_partition.cpp/hpp    # MPI domain decomposition support

├── solve/
│   ├── cpu/                        # CPU solvers (OpenMP parallel where needed)
│   │   └── elasticity_solver.cpp/hpp

│   ├── gpu/                        # GPU solvers (MFEM Device / CUDA)
│   │   ├── elasticity_gpu.cpp/hpp  # MFEM on GPU
│   │   └── kernels/                # Raw CUDA/HIP kernels (if needed)
│   │       ├── curvature_kernels.cu
│   │       └── traction_kernels.cu

│   ├── mpi/                        # Multi-rank coordination, halo exchange
│   │   └── mpi_solver_driver.cpp/hpp

│   ├── solver_manager.cpp/hpp      # Chooses solver (CPU/GPU/MPI) based on config

├── analysis/
│   ├── stress_analysis.cpp/hpp     # Stress, strain, von Mises, energy
│   ├── surface_analysis.cpp/hpp    # Curvature, traction, gamma
│   ├── region_analysis.cpp/hpp     # Region-based stats
│   └── result_fields.cpp/hpp       # Field construction for output

├── output/
│   ├── results_writer.cpp/hpp      # CGNS/VTU output writing
│   ├── logger.cpp/hpp              # Logging (rank-aware, can be silenced)
│   └── timers.cpp/hpp              # Timing utilities (per-rank or aggregated)

├── utils/
│   ├── math_utils.cpp/hpp          # Tensor math, numerical ops
│   ├── device_utils.cpp/hpp        # CUDA helpers: device selection, sync
│   └── string_utils.cpp/hpp

├── tests/                          # Unit tests
│   └── test_memory.cpp

└── scripts/                        # Python helpers (optional)
    ├── convert_to_cgns.py          # Convert mesh/mask to CGNS
    └── launch_slurm.sh             # SLURM launcher

🚀 Runtime Phases (Driven by main.cpp)
1. MPI & GPU Initialization
MPI_Init(...);
int rank;
MPI_Comm_rank(MPI_COMM_WORLD, &rank);

// Set device for each rank
DeviceManager::SetDeviceByRank(rank);

// Initialize MFEM (sets device)
Device device("cuda");  // or "cpu" / "hip"
mfem::Device::Configure(device);

2. Read Config
SimulationConfig config = CGNSInterface::Load("input.cgns");

3. Run Simulation
MirpSim sim(config);
sim.Run();

4. Finalize
MPI_Finalize();

    void SyncToHost(const std::string& label);
    ...
};

Access Pattern

Allocate shared data globally

Use memory.Get<>() in any module that needs it

Fields like displacement, stress, curvature, region tags, etc.

Multi-GPU

🔌 SLURM Launch

You can run your job via SLURM like:

srun -n 4 ./mirp_sim input.cgns


Or with job script:

#!/bin/bash
#SBATCH -N 2
#SBATCH -c 8
#SBATCH --gres=gpu:4
#SBATCH --time=01:00:00

srun ./mirp_sim input.cgns

✅ Final Notes
Feature	Supported?	Notes

Surface curvature	✅	CPU + optional CUDA kernel

CGNS input/output	✅	Controlled via config/ module
VTK export	✅	Optional for ParaView
MPI parallel	✅	ParMesh + ParFES + ParGridFunction
Multi-GPU	✅	Each MPI rank uses a separate GPU
OpenMP CPU parallelism	✅	In CPU solver modules
CUDA GPU acceleration	✅	Via MFEM + raw kernels if needed
Region-wise materials	✅	Read from CGNS
